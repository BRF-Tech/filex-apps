# Spanish language pack

The whole filex interface in Spanish - the file explorer, the admin panel, the settings dialog and
the public pages a share link opens - as a **language pack**: one `filex-app.json`, no code, nothing
that runs.

- Written against the filex 0.51.0 catalogue: 5,502 of 5,502 strings, including the text the server
  writes.
- Neutral, international Spanish, addressing the reader as *usted*.
- After installing it, pick **Español** in **Settings > Preferences > Language**, or in the language
  row at the bottom of a public share page.

**AI-translated, awaiting review by a native speaker.** It is complete and checked mechanically, but
it may still read unnaturally in places. Corrections are welcome as issues or pull requests:
[github.com/BRF-Tech/filex-lang-es](https://github.com/BRF-Tech/filex-lang-es).
